# 端渡 DuanDu

[English](README.md) · 简体中文

**状态：这是一个实验性质的测试项目，目前还没有可用版本。**

端渡是一个关于跨平台设备协同的小实验。想解决的问题很简单：自己的设备分属不同生态，却需要安装和配置一堆工具才能勉强配合起来。

这个想法来自很普通的使用环境：Windows 用来玩游戏，macOS 用来工作，Android 是主力手机，偶尔还会使用 iOS 和 Linux。在这些设备之间传文字、截图、通知和文件，至今还是有些麻烦。

## 想尝试的事情

- 在不同设备之间同步剪贴板
- 截图后发送到另一台设备，并按需自动复制
- 在系统允许的情况下转发 Android 通知和短信
- 在条件允许时开启另一台设备的热点
- 优先使用本地连接，必要时经过加密中继
- 为自建服务保留空间

这只是目前的大致方向。有些想法可能会调整，也可能因为平台限制而无法完整实现。

## 当前进度

项目还在探索阶段，目前主要在梳理真实使用场景、不同平台的限制、隐私方案，以及第一版到底应该做什么。

现在还没有可以下载的软件，仓库中的内容也可能随着项目逐渐成形而变化。
